# Django-прототип системы проката бытовых инструментов

Проект демонстрирует программный прототип для раздела 3.2 выпускной работы. В нем реализованы основные сущности предметной области: клиенты, пункты проката, сотрудники, категории инструмента, инструменты, тарифы, договоры аренды, позиции аренды, возвраты и обслуживание.

## Роли пользователей

В прототипе используются три прикладные роли:

| Роль | Логин | Пароль | Возможности |
|---|---|---|---|
| Администратор | `admin_demo` | `admin123` | Просмотр всех разделов, добавление инструмента, оформление аренды, возвраты, обслуживание, отчеты, доступ к `/admin/` |
| Сотрудник пункта проката | `orlova` | `employee123` | Работа с клиентами, арендами, возвратами и обслуживанием в своем пункте проката |
| Руководитель | `manager_demo` | `manager123` | Просмотр данных, контроль договоров, возвратов, обслуживания и отчетов без выполнения операционных действий |

## Запуск

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

macOS / Linux:

```bash
source venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Создание базы, миграций и тестовых данных:

```bash
python setup_demo.py
```

Запуск сервера:

```bash
python manage.py runserver
```

После запуска откройте в браузере:

```text
http://127.0.0.1:8000/
```

Система перенаправит на страницу входа. Используйте одну из демонстрационных учетных записей из таблицы выше.

## Что можно показать на защите

- вход в систему под разными ролями;
- различие меню и доступных действий для администратора, сотрудника и руководителя;
- главную панель с показателями;
- список инструментов с фильтрацией по статусу;
- список клиентов;
- действующие и завершенные договоры;
- оформление новой аренды от лица сотрудника пункта проката;
- регистрацию возврата;
- передачу инструмента на обслуживание;
- завершение сервисной операции;
- отчетную страницу для руководителя;
- административную панель Django для роли администратора.

## Административная панель

Демо-пользователь `admin_demo` уже имеет права администратора Django. После запуска проекта можно открыть:

```text
http://127.0.0.1:8000/admin/
```
